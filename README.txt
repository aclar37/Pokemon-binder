POKEMON BINDER TRIAL - GITHUB PAGES

1. Create a PUBLIC GitHub repository, for example pokemon-binder.
2. Open the repository, choose Add file > Upload files.
3. Upload the CONTENTS of this folder (index.html, cards.json, and images folder).
   For reliable folder upload, unzip on a computer and drag all files/folders together.
4. Go to Settings > Pages > Build and deployment.
5. Source: Deploy from a branch; Branch: main; Folder: /(root); Save.
6. Wait a few minutes and visit https://YOUR-USERNAME.github.io/pokemon-binder/

To update: replace cards.json and add images, commit the changes. Changes will go live after deployment.
